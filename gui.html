计费周期内（官方口径）

—
两套账为什么要分开看：
· 官方统计全部客户端的计费，口径是滚动窗口（5 小时 / 7 天）与订阅周期，只按 credit 值算。
· 本地只统计经 cmc-proxy 转发的请求，口径是你给的任意时间区间，费用按 goat-prices.json 的牌价估算。
· 两者在同一区间内应当基本一致；不一致通常来自：本地日志开启之前的请求、没走 cmc 的客户端、以及官方计费的取整。
· 官方这几个接口是只读 GET，查询不消耗额度。
modelMap 是「客户端请求名 → 上游模型」的精确映射。Claude Desktop 只会发 Claude 系名字， 想用别的模型就把它挂在对应壳名下面。
注意：[1M] 后缀不参与精确匹配，所以 [1M] 变体必须单独写一条 —— 保存时下面会自动同步。

官方额度

启用查询 出网代理
为什么需要代理：官方接口在境外。直连不通时填上你的本地代理（v2rayN 默认 HTTP 入站 127.0.0.1:10809）。
改代理后要重启控制台才生效 —— Node 的 fetch 在第一次请求时就固定了 dispatcher，之后改变量不再起作用。
